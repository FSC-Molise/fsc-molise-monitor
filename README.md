# FSC Molise 2021-2027 — Piattaforma di Monitoraggio

**Regione Molise — Servizio Coordinamento FSC — Dott. Leonardo Giuliano**

## Deploy su GitHub Pages

1. Crea repository su GitHub (es. `fsc-molise-monitor`)
2. Carica **tutti i file e la cartella assets/** di questo pacchetto
3. Settings → Pages → Branch: main → Folder: / (root) → Save
4. Live su `tuousername.github.io/fsc-molise-monitor/`

## Connessione Google Sheets

Nella sezione **Gestione** della piattaforma trovi 3 campi:
- **Sheet ID**: la stringa tra `/d/` e `/edit` nell'URL del foglio Google
- **API Key**: chiave API da console.cloud.google.com (con Google Sheets API abilitata)
- **URL Apps Script**: URL del deployment dello script per la scrittura (opzionale)
